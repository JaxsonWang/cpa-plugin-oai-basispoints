日期：2026-09-30（UTC+8）。仅发布插件，不修改 CPA 主程序、生产配置、凭据或现有部署，不自动重启服务。

## 发布范围

- HTTP、SSE、WebSocket 和图片上传统一使用当前完整 OAuth 凭据生成请求头，读取账号用户 ID 与白名单会话头。
- `captured_headers` 优先于同名 `headers`；executor 的 `header:*` 属性仅替换解析用的 `headers`，不会覆盖独立的 `captured_headers`。
- 支持字符串及字符串数组，保留非空项顺序；控制字符与超长值明确返回 401，Cookie 和未知头不转发。
- token、账号 ID 和认证模式由当前凭据决定，捕获头不能补齐或覆盖这些身份字段；协议头固定生成，客户端输入不注入上游身份。
- 错误在截断前及 JSON 解码后脱敏，保留真实 403，不通过换号、重放或伪造成功绕过失败。
