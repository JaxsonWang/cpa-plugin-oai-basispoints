## 本次改动

上游 WS 终态前断开时，保留真实状态及错误类型，并附加当前尝试的安全进度信息：

| 字段 | 含义 |
| --- | --- |
| `elapsed_ms` | 当前 WS 尝试开始发送后经过的毫秒数，不包含握手或宿主前序尝试 |
| `event_idle_ms` | 最近一个完整有效应用事件后的毫秒数；无事件则从发送开始计时 |
| `events` | 已读取并解析的应用事件数 |
| `received_bytes` | 上述应用事件的载荷总字节数，不包括 WS/TCP 帧开销 |
| `last_event` | 精确白名单中的末事件；无事件为 `none`，未知名称为 `other` |
| `delivery_started` | 插件是否已启动向宿主交付，不代表客户端已经接收 |

不保存或回显正文、工具参数、任意事件名称、关闭原因、底层自由文本或凭据。事件统计不包含 Ping/Pong，因此 `event_idle_ms` 不等于网络无流量时长。没有添加主动心跳、额外重试、HTTP 重放或新的配置项；取消、超时、大小限制仍走原分类。
