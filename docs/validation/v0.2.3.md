# v0.2.3 验测说明

日期：2026-09-28（UTC+8）。本次只修改插件；正式发行包由既有 GitHub Actions 工作流从 `v0.2.3` 标签构建和发布，不修改 CPA 主程序，也不自动替换或重启 NAS 服务。下文区分本地候选验测与正式发行包。

## 修复范围

- 每份源 OAuth 文件仍展开原生 Codex 和 Basis Points 两条内存认证，但虚拟认证使用独立的 `oai-basispoints/bp-<源文件标识>` 查询名称。
- 原生认证保留原模型，虚拟认证显示配置的 Basis Points 模型；这是两条分别展示的记录，不是将两个执行器伪装为同一条认证。
- 认证 ID、执行器、令牌存储与请求调度不变；虚拟名称不是磁盘路径，不创建另一份 OAuth 文件。
- 刷新响应省略 ID、FileName 和 Label，由宿主保留原有身份，不再从路由 ID 推导新文件名。
- 虚拟查询名称的 basename 也不同于源文件名，避免被宿主当作源文件编辑入口。源文件 WS 编辑继续使用「Basis Points 源认证」。

## 复现

在干净检出目录执行：

```bash
go test -race ./... -count=1 -timeout=180s
node --test internal/basispoints/source_auth_page.test.mjs
go vet ./...
go mod tidy -diff
CGO_ENABLED=1 go build -buildmode=c-shared -o /tmp/oai-basispoints.dylib ./cmd/basispoints
python3 scripts/verify_auth_model_names.py \
  --host /absolute/path/to/official/cli-proxy-api \
  --plugin /tmp/oai-basispoints.dylib \
  --output /absolute/path/to/validation-output
```

脚本只使用本地合成账号与 HTTP/SSE 上游，隔离宿主 HOME 和外部存储环境，并在退出时停止测试进程。原生模型验证是目录及注册基线比较，不声称完成真实 OpenAI 原生推理或真实 Basis Points 验收。

## 正式发行包

- 沿用 macOS、Linux、Windows 的 amd64/arm64 六平台构建，不修改既有插件商店源或安装契约。
- 正式包来自标签对应源码，通过测试和构建门禁后上传；每个平台的 ZIP 仅包含一个按原名称命名的插件动态库。
- 发行包摘要以 GitHub Release 的 `checksums.txt` 为准。本地候选使用交叉编译工具链，正式 Linux 包使用 manylinux2014，因此不能用上面的本地 SO 哈希校验正式发行包。
- 发布不会覆盖用户 Downloads 中的本地候选，也不会操作 NAS。真实账号的模型权限、令牌有效期和上游 WS 支持仍需部署后按实际环境验收。
