# v0.2.2 验测说明

## 变更范围

- 只修改 Basis Points 插件，不修改 CPA 主程序。
- 新增「Basis Points 源认证」菜单及受 CPA 管理鉴权保护的 GET/PATCH 接口；公开资源仅提供静态页面，不包含账号令牌。
- 写入只接受 `auth_index` 与布尔值 `websockets`，重新读取源文件并原子替换；保留原 OAuth 数据、扩展字段及大整数，不创建重复认证文件。
- 新增可选管理密钥记忆，默认关闭。验证成功后才写入当前站点的浏览器存储；下次进入自动连接但不回显密钥。取消勾选或清除连接可删除，401/403 会清除失效密钥，存储错误明确提示。
- 浏览器存储不是加密保险库，同源脚本可以读取；仅建议在可信个人设备上通过 HTTPS 使用，不跨浏览器、协议、域名或端口同步。

## 本地验证

| 范围 | 结果 |
| --- | --- |
| Go 测试及子测试 | 666 项通过，启用 race 检查，无失败或跳过 |
| 页面行为测试 | 16 项通过，直接运行实际嵌入页面脚本 |
| 静态检查 | `go vet`、格式及差异空白检查通过 |
| 原版宿主 | CPA v7.3.19 在 macOS ARM64 加载本地插件，真实动态库 ABI 调用通过 |
| 传输与热重载 | WS 关闭→开启→关闭，每次分别验证流式和非流式，共六组通过 |
| 源认证保护 | 大整数和未知字段保留；拒绝匿名读写、非法字段、路径及符号链接；没有重复认证文件 |
| Chrome 页面 | 默认不记忆；记忆后新页面自动连接；取消记忆保留当前连接但重载不再自动连接；清除连接及错误密钥不留存 |
| Linux AMD64 候选 | ELF 架构、共享库格式和四项插件 ABI 导出校验通过 |

页面测试覆盖非 JSON 的 401/403、网络失败、临时服务端错误，以及浏览器存储拒绝读、写、删除的情况。失败不会伪装为保存成功；清除失败保留可重试入口。密钥只通过 Authorization 请求头发送，不加入 PATCH 正文、URL 或源认证 JSON。

测试使用合成账号和本地上游，不使用真实管理密钥；浏览器验测通过页面交互和重载确认，没有读取浏览器凭据存储。

## 可复现命令

在干净源码检出目录执行：

```bash
go test -race ./... -count=1 -timeout=180s
go vet ./...
node --test internal/basispoints/source_auth_page.test.mjs
go mod tidy -diff
go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12
```

## 发布与验证边界

- GitHub Release 沿用六平台构建流程，标签版本必须与插件版本一致；发布包包含校验和，插件商店继续使用现有 `github-release` 安装协议。
- 本地原版宿主集成采用 macOS ARM64 与合成上游，不等于 Linux NAS 部署验收，也不代表真实上游账号 WS 可用性。
- 不改变 `upstream_transport: auto` 的凭据开关条件、已有回退范围或禁止重复生成的规则。
- 不自动替换或重启现有部署。安装新版 SO 后需重启 CPA，并确认加载版本为 `0.2.2`。
- 发布不包含本地账号诊断记录、认证文件、管理密钥或其他现场数据。
